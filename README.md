## Bu depo hakkında

Kaydırdıkça değişen, kitap okur gibi ilerleyen tek sayfalık bir hikâye sitesi.
Çizimler kodda SVG olarak durur ve [Rough.js](https://roughjs.com/) ile elle
çizilmiş görünüme kavuşur.

- **İki dil:** Türkçe ve İngilizce. İlk ziyarette tarayıcının dili seçilir; `?lang=en` ya da `?lang=tr` ile doğrudan açılabilir.
- **Gündüz ve gece modu:** Gündüz açılır, sağ üstteki düğmeyle geceye geçer, seçim hatırlanır.
- **Mobil uyumlu:** Telefonda çizim üstte, metin altta; üst çubukta dil ve tema düğmeleri.

| Katman | Seçim |
|---|---|
| Çatı | Vite + React 19 + TypeScript |
| Çizim | Rough.js (yalnızca üreteci; yollar React'te çizilir) |
| Yazı tipleri | Newsreader, Inter, Caveat (Google Fonts) |
| Yayın | GitHub Pages, GitHub Actions ile |

### Dosyalar

| Dosya | İçerik |
|---|---|
| `src/data.ts` | Sitedeki bütün yazılar, Türkçe (`tr`) ve İngilizce (`en`) |
| `src/i18n.tsx` | Dil seçimi |
| `src/components/Controls.tsx` | Dil ve gece/gündüz düğmeleri |
| `src/components/Scenes.tsx` | Altı sahnenin çizimi |
| `src/components/sketch.ts` | Rough.js ile çizgi, tarama ve renk lekesi |
| `src/components/Story.tsx` | Kaydırmalı hikâye ve proje kartları |
| `src/components/Panel.tsx` | Yan panel: deneyim, eğitim, proje ayrıntısı |
| `src/styles.css` | Renkler (`:root`) ve görünüm |
| `public/llms.txt` | Yapay zekâ ajanları için kısa profil |
| `METINLER.md` | Yazıların düz metin hâli, düzenlemek için |

### Çalıştırma

```bash
npm install
npm run dev
```

Derleme: `npm run build` (çıktı `dist/`).

### Yayın

`main` dalına her gönderimde `.github/workflows/deploy.yml` siteyi derleyip
GitHub Pages'e yükler. İlk seferde deponun **Settings → Pages → Source**
ayarı **GitHub Actions** yapılır. Depo adı `Ssillaa.github.io` olduğu için
site `https://ssillaa.github.io/` adresinde açılır.
